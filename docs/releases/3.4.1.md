# Calliope CLI 3.4.1

Native Bedrock inference and model discovery now use the official AWS SDK
credential providers. ECS tasks, web-identity workloads, shared profiles, SSO,
role assumption and process credentials can supply renewable identity without
exporting static keys or installing the AWS CLI for inference.

Explicit profiles fail if unavailable instead of falling through to an unrelated
ambient identity. Each request takes a fresh credential snapshot. Resolution has
a ten-second limit and cancellation removes its credential-worker process tree;
credential values and external helper errors stay out of diagnostics.

The standalone binaries retain Calliope's environment-file precedence, including
for the private credential worker. Packaging checks exercise the real SDK and
helper cancellation on each supported target. Region configuration and gateway
behavior are documented in [providers](../providers.md#aws-bedrock).

Refs: [#416](https://github.com/calliopeai/calliope-cli/issues/416).
