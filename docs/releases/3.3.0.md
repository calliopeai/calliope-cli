# Calliope AI CLI 3.3.0

Status: **published**. The CLI joins the Agent Host Protocol and ships as signed
standalone binaries, with Windows supported end to end.

- **`calliope attach`**: follow a live agent session running on a user's agent
  host and approve its tool calls from the terminal. Through a Calliope AI hub,
  `calliope attach --hub <url> --user <name>` finds the host with the user's hub
  token. Verified live against a Workbench hub: session listing, following, and
  approval. Approvals that were already pending when attach joins are shown in a
  follow-up (#391).
- **ACP `session/load`**: an agent host restores Calliope sessions after a restart.
- **Signed per-platform binaries** for embedders, including `win-x64`, with an
  attested `calliope-binaries.json` manifest.
- **Windows**: session snapshots, `brain init` and every store now work; the
  Windows binary passes the same smoke test as every other platform.
- **Typed judgments and policy**: `calliope judge`, `policy.judgment`, and budget
  controls on the `evaluate()` library entry.
- **Node.js 24** is the supported floor.

See `CHANGELOG.md` for the full list.
