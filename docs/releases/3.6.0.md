# Calliope CLI 3.6.0

This release adds reviewed host execution and a packaged code migration kit.
It retains the provider retirement and credential-redaction fixes from 3.5.4.

## Reviewed host execution

Embedded hosts can bind remote children to a reviewed native run, its owner,
workspace and original allowance. The parent ledger retains reservations across
process restarts and refuses new work after exhaustion, cancellation or revoked
authority. Native questions, outcomes and retained sessions preserve their account
binding. This adds no separate scheduler or replacement root budget.

`calliope --version --json` advertises headless protocol 1, delegation 1 and
workspace binding 1. ACP remains protocol 1. Hosts must negotiate the applicable
capability and provision the reviewed authority explicitly; an ordinary ACP
session is not delegated execution.

See [the delegation contract](../delegation-ledger.md) for credential delivery,
private retained state, workspace binding and the runnable process qualification.
The source qualification uses deterministic inference with real ledger and child
processes. Deployment through Astrolift and Cykick requires separate consumer
qualification; publishing this CLI does not establish their remote acceptance.

## Code migration kit

`calliope migration` packages committed-source inventory, baseline verification,
candidate verification and reviewed assessment. The initial adapter covers
self-contained JavaScript `.mjs` to TypeScript `.mts` command-line programs on a
pinned Node 24 Linux image. Verification preserves exact source/rule/runtime pins,
tests a declared negative control and retains command and cleanup evidence.

The [migration playbook](../migration-playbook.md), schemas and example evidence
ship with the npm package. Verification requires the reviewed digest and an
already-present container image. Reports do not authorize execution, and passing
the declared cases does not prove general program equivalence. The kit reuses
native execution authority and bounded improvement; it does not provide
cross-run learned policies or model-weight training.
