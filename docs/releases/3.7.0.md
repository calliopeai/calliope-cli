# Calliope CLI 3.7.0

This release adds durable ACP session controls, tightens reviewed inference
admission, and publishes a versioned discovery contract for native improvement
hosts. It retains the LiteLLM retirement and Hugging Face support from 3.6.0.

## ACP session controls

ACP clients can change Work/Plan mode through `session/set_mode` and choose a
model through `session/set_config_option`. Model choices come from live provider
discovery. Saved controls survive process restart; stale or concurrent updates
refuse instead of overwriting another client. Plan mode denies mutating tools.
Delegated sessions retain their parent's model authority.

The stable ACP wire protocol and `--version --json` remain unchanged. Clients
must negotiate `_meta.calliopeSessionControls.version: 1`; an older CLI does not
promise these controls. See the [ACP contract](../acp.md).

## Reviewed inference authority

New remote-ledger reservations must match the current admitted agent's explicit
provider/model choices. The host rechecks those constraints under the ledger
writer lock, including for newly admitted descendants. Rejected choices leave
the parent's allowance unchanged; already-admitted requests retain their replay
and settlement semantics.

The Node and standalone qualifications use real child and ledger processes with
deterministic local inference. Task/attempt and endpoint authority, Smart routing
stage binding and actual disposable Astrolift parent/child acceptance remain in
[#415](https://github.com/calliopeai/calliope-cli/issues/415). This release does not
claim those deployment requirements are complete.

## Native improvement host discovery

`calliope improve host-capabilities --contract-version 1 --json` reports the
installed native execution, review-request, task-outcome and source-proposal
interfaces with independent versions. It does not open the caller's project or
grant execution authority. Unsupported versions and execution selectors refuse;
the existing `improve capabilities` response remains compatible.

The declaration includes the installed package version and build source metadata
when available. Metadata is self-reported, not proof of authenticity: verify npm
integrity and provenance, or native checksums and attestations, against the release
tag and source commit. Missing, dirty or invalid metadata cannot establish a
released build. See the [improvement host contract](../improvement-cycles.md).

External feedback import, cross-run learned strategy selection and model-weight
training remain unavailable. SDK 7 recapture work remains separate from this
release; xAI live qualification remains deferred.
