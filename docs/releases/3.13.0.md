# Calliope CLI 3.13.0

Explicit tool approvals for trusted headless SDK hosts.

- Hosts can opt into the versioned `approveTool` callback to allow, reject or
  cancel one exact tool request at its saved session checkpoint.
- Approval waits use the runtime's original cancellation signal and deadline.
  Changed conversations, task revocation, rejected or invalid decisions and
  callback failure prevent tool execution.
- Existing permission, hook, scope and ledger checks remain enforced after the
  decision and before the effect. Question answers do not grant tool authority;
  hosts without this capability retain their existing defaults.

Consumers must check `HEADLESS_TOOL_APPROVAL_PROTOCOL_VERSION === 1` and bind
their callback to their reviewed execution authority. This SDK capability does
not install an approval policy or qualify a remote deployment by itself.
