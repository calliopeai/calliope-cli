# Calliope CLI 3.5.1

A host can now run a delegated child that spends from its parent's allowance.
After granting the child through the parent's served ledger, start a headless
run with `--ledger-url`, `--ledger-token-file` and `--ledger-agent`. The turn
runs under the child's grant: its tools, paths, deadline and budget, with every
provider request reserved and settled by the parent. A revoked or unknown grant,
or an unreachable parent, stops the child before any turn. See
[running a delegated child](../delegation-ledger.md#run-a-delegated-child).

Also fixed: the child's local ledger cache resolves to a canonical path, so the
execution guard no longer refuses delegated children on macOS, whose temporary
directory is an alias.

Refs: [#415](https://github.com/calliopeai/calliope-cli/issues/415).
