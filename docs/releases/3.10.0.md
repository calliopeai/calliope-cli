# Calliope CLI 3.10.0

Context admission, runtime checkpoint evidence and consistent cost estimates for
hosts running longer agent tasks.

- Compression, request admission and provider transport share conservative input
  sizing and the effective output allowance. Reviewed limits fill missing live
  metadata while retaining smaller live limits, caller caps and eligibility gates.
  A request that cannot fit holds instead of silently truncating its task.
- Anthropic non-streaming sizing applies the adapter's existing output ceiling
  before reserving budget, including compression requests.
- Headless hosts can opt in to durable runtime checkpoint evidence and exact
  acknowledgment before provider, tool and verifier effects. Cancellation keeps
  returned usage and final local state; a failed write or rejected acknowledgment
  still fails the run. Original counters, deadlines and unknown usage remain held.
- Guarded and project-capped response estimates use their admitted quote rates and
  the ledger's nanodollar rounding. Journals label this basis as `admission`.
  Conservative admission estimates are distinct from invoice charges. Subscription
  usage retains zero-dollar semantics, and missing usage remains unknown.

Checkpoint capture does not grant a replacement worker or implement cold restart
recovery. Hosts must qualify execution ownership and original ledger continuation
separately before resuming an interrupted process. Historical charges are not
repriced, and unknown reservations are not released by this update.
