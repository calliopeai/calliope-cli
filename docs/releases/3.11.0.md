# Calliope CLI 3.11.0

SDK support for hosts that keep one original allowance across isolated task
workspaces.

- Headless ledger hosts can supply their own fetch transport. A trusted local
  bridge can carry delegated ledger requests without exposing the parent host's
  control socket or signing key to a worker.
- Hosted tasks retain the original ledger and account lineage while binding
  their own workspace identity. A different workspace does not create another
  allowance or reset the original deadline, spend or unknown reservations.
- Accounted provider responses can be retained through the runtime checkpoint
  boundary before presentation and final state acknowledgment. Interrupted
  callers preserve returned usage and response evidence for host reconciliation.

These are opt-in host contracts. They do not implement automatic executable cold
restart or grant a replacement worker execution authority. Hosts still qualify
current ownership, retained receipts and the original ledger before continuation.
API cost estimates remain distinct from provider invoices; subscription and
missing-usage semantics are unchanged.
