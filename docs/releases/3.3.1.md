# Calliope AI CLI 3.3.1

Status: **published**. A patch release for `calliope attach`.

- **Approvals already waiting when attach joins** are now asked about. attach
  reads the chat snapshot and prompts for each tool call pending confirmation,
  and actions sent right behind the snapshot are no longer lost (#391).
- **Approvals inside a Claude subagent** are asked about too. attach follows the
  session's `inputNeeded` and answers on the subagent's chat and turn. A call
  listed in both places is asked once (#394).
- **Prompts close by themselves** when another client answers, the turn ends or
  the connection drops.

Works against agent hosts before and after calliope-vscode#823 and #824. Ship
this before an agent host image that carries #824, so attach users keep seeing
subagent approvals.

See `CHANGELOG.md` for details.
