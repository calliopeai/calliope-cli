# Calliope CLI 3.5.3

This security patch replaces the deprecated ACP package and its vulnerable
Zod 3 dependency with the maintained `@agentclientprotocol/sdk` 2.0.2 and
Zod 4.6.6. ACP clients continue to use protocol version 1.

Incoming ACP messages are bounded before schema validation. Over-limit
requests receive an invalid-parameters error before a session or inference
starts, while valid follow-up requests can still use the connection.
Session restoration, permission decisions, cancellation and editor file
delegation retain their existing behavior. See [ACP limits](../acp.md).

The release also includes fast-uri 3.1.9 and the reviewed dependency update
group. The resolved dependency tree reported zero known vulnerabilities
in the pre-release npm audit; this is not a claim of complete security.

Refs: [#433](https://github.com/calliopeai/calliope-cli/issues/433),
[#432](https://github.com/calliopeai/calliope-cli/pull/432),
[#429](https://github.com/calliopeai/calliope-cli/pull/429).
