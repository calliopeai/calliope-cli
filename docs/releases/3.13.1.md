# Calliope CLI 3.13.1

Headless SDK hosts can pass `deadlineMs` to preserve the original cutoff
across separately started runs. The SDK records that exact value in runtime
evidence and stops work when the remaining time expires.

Check `HEADLESS_ABSOLUTE_DEADLINE_PROTOCOL_VERSION === 1` before supplying the
option. Use either `deadlineMs` or `maxTime`. Retained recovery continues to
use the deadline saved in its original checkpoint.
