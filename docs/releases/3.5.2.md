# Calliope CLI 3.5.2

An approval policy now sees what it approves. When `calliope run approve` asks
permission for `orchestration_approve`, the arguments passed to `policy.command`
and judgment include the prepared `plan` (agents, tools, paths and limits) beside
`runId`, `planHash` and `revision`. A policy can judge the exact plan the hash
covers instead of approving a bare id. Cancellation is unchanged.

Also fixed: a delegation ledger token is accepted only in its canonical
spelling. A second spelling of the same signature, differing only in the final
character's ignored padding bits, was accepted before; it granted nothing more,
but a token now has exactly one valid form.

Refs: [#424](https://github.com/calliopeai/calliope-cli/pull/424),
[cykick#80](https://github.com/calliopeai/cykick/issues/80).
