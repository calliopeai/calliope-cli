# Calliope AI CLI 3.2.0 release preparation

Status: **unpublished; release gates remain blocked**. The package version is
prepared for 3.2.0; npm still serves 3.1.0. No release tag or publication is implied.

The foundation shares turn execution and permissions across terminal, headless
and ACP, propagates cancellation, loads trusted scoped instructions, preserves
Bedrock reasoning state and uses Google's `@google/genai` SDK. DeepSeek, xAI and
Cerebras use provider profiles; AI21 is retired. The conformance suite exercises
the installed SDKs through intercepted HTTP and separately replays real captures.

This release preparation corrects the active conformance matrix, adds an offline
machine-readable readiness inventory, and bounds live probes with persistent
dollar reservations. Strict model discovery exposes failed requests instead of
reporting emergency fallbacks as current provider evidence.

REPL controls add live provider/model validation, health and discovered metadata
in pickers, session-only switching, `/once` turn overrides, and `/defaults` for
trusted project preferences. CLI invocation flags and ACP share the same
preference resolution; queued messages keep independent choices. See
[Model preferences](../model-preferences.md).

The provider health layer adds local observations, `/doctor` and headless JSON
diagnostics, bounded discovery probes, and quarantine with explicit recovery.
See [Provider health](../provider-health.md) for the schema, metric definitions,
retention, CI import/export, and recovery procedures.

```sh
npm run test:coverage -- --maxWorkers=2
npm run test:conformance
npm run test:conformance:release
npm run build
npm run bench
node scripts/conformance/report.mjs --json --require-ready
```

Publication is conditional on current passing evidence, clean install/headless
smokes, a secret-free clean git tree, green CI and the applicable approval gates.
Never bypass `prepublishOnly` to work around missing captures.

Session recovery now uses bounded, private snapshots with explicit revisions
and preserves tool/reasoning metadata at runtime checkpoints. `/new`, `/sessions`
and validated `/resume` support separate terminals and interrupted work; see
[recovery procedures](../session-recovery.md).

Recorded session history adds `/branch`, `/checkout`, `/diff`, `/replay`, private
`/export` and `/import`, and `calliope session ... --json`. Terminal, headless and
ACP save a safety branch before the first allowed risky action of each turn;
replay never executes recorded tools. See [session history](../session-history.md)
for schema, limits, policy enforcement and recovery boundaries.
