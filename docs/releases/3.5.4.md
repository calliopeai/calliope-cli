# Calliope CLI 3.5.4

LiteLLM is retired as a CLI provider. It is no longer offered by setup, model
discovery or request routing. Explicit legacy selections fail before a network
request and do not select a replacement provider automatically. Existing stored
settings are preserved but ignored; select a supported provider to continue.

Hugging Face remains supported. Historical LiteLLM wire captures remain available
for provenance, but are excluded from active provider qualification. The release
gate covers all 16 non-deferred adapter paths; xAI remains explicitly deferred.

Brain output now also redacts stored provider keys that are overridden by an
environment credential, including retained keys for retired providers.

This patch includes the Zod 4.6.6 and ACP validation fixes published in 3.5.3.
ACP stays at protocol version 1.
