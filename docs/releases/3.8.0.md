# Calliope CLI 3.8.0

This release adds explicit subscription access, native task-bound delegation and
reviewed feedback. It also tightens reviewed inference authority and reads
Mimwell portable knowledge graphs.

## Experimental subscription access

`calliope auth chatgpt login` selects ChatGPT-plan access for the OpenAI provider.
Account selection, private credential storage, refresh/revocation and live model
discovery are separate from API-key access. Streamed Responses and tool calls use
Calliope's existing permission loop. Expired sessions stop; quota exhaustion can
use an explicitly configured paid API-key fallback. Subscription requests refuse output-token
and USD enforcement that the service cannot provide; USD totals exclude this
consumption. See [ChatGPT plan access](../chatgpt-plan.md).

Quota and rate-limit circuits persist across processes. Opt-in API-key fallback
reserves every paid request against a shared project ceiling, preserves public
conversation/tool context and strips encrypted subscription state. Paid sessions
stay on their selected model; partial output, cancellation, logout and reviewed
execution stop automatic transitions. A depleted API account stops without
retrying or switching back. Missing live/reviewed billing bounds refuse payment.

`calliope claude -- <prompt>` delegates a complete session to the installed,
authenticated official Claude Code CLI. `calliope claude status` checks that local
setup. Claude owns permissions, tools, sessions and plan usage; Calliope's native
sandbox and budgets do not govern the delegated session. See
[local Claude plan delegation](../claude-plan.md).

These integrations ship as opt-in experimental features. Tests use synthetic
authentication and response fixtures; live account eligibility and subscription
prompt/tool round trips remain unqualified. Complete the user-operated checks in
the linked guides before relying on either route for unattended work.

## Reviewed task authority and feedback

Delegated headless and ACP execution can bind to an exact native task attempt,
including its owner, output cap and original accounting across host restarts.
Completed or mismatched attempts refuse new inference. Reviewed Smart routing
pools and provider endpoints now constrain new reservations; an endpoint change
requires new review, while prior admissions retain replay and settlement.
See [delegation ledger](../delegation-ledger.md).

Version-2 improvement host discovery exposes reviewed task feedback. Receipts bind
an assessment to the exact observed completed attempt and retain private journal
evidence. They neither mark a task accepted nor activate a learned policy. See
[task feedback](../task-feedback.md). External placement and disposable remote
parent/child acceptance remain tracked in #415; cross-run learned strategy
selection remains tracked in #413.

## Compatibility and runtime

- `brain import` accepts `mimwell-kg/v1` alongside existing graph formats; exports
  continue using `calliope-kg/v1`.
- OpenAI SDK 7 stream capture handling now recognizes delivered completion events.
  Runtime SDKs, Conf, Ink and supporting dependencies are updated; container builds
  include the metadata builder.
- Node 24 or later is required. The stable ACP wire protocol remains version 1.
- Mistral/Hugging Face SDK 7 live qualification follow-up remains in #457; xAI is
  explicitly deferred by the existing publication gate.

Performance budgets from #210 remain enforced for cold start, keystroke rendering
and retained-session heap growth. See [performance measurements](../performance.md).
