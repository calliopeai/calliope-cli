# Calliope CLI 3.8.2

This patch preserves coordinator cancellation when an atomic approval update
lands during a read. The reader discards the replaced descriptor and checks the
current private file, with at most three attempts. A revoked approval still
stops execution; malformed records, unsafe files, in-place changes and repeated
replacement still refuse. No authority, deadline or budget is refreshed.

Deterministic publication regressions cover unchanged approval and revocation,
plus denied storage cases. Real cross-process cancellation checks retain their
exit-code, closed-request and journal-replay assertions, and now include child
output when the exit code is wrong.

Includes the headless effort and usage-presence changes described in
[3.8.1](3.8.1.md). Node 24 or later remains required. Synthetic transport tests do
not qualify a paid account or remote subscription factory route.

Refs: #509.
