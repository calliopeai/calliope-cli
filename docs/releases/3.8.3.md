# Calliope CLI 3.8.3

Headless hosts can answer a question within the original turn and acknowledge a
frozen receipt only after the SDK saves that exact answer in its conversation.
Execution waits for the acknowledgment under the original session, cancellation,
deadline and cumulative budget. Host rejection, checkpoint failure and concurrent
conversation changes stop continuation. Generic error retries cannot bypass the
receipt barrier.

This release also rejects echoed requests and malformed messages as stdio MCP
replies. Valid null results, object results and server errors keep their existing
behavior.

The SDK callbacks are integration primitives. Hosted Factory routing, steering,
execution pause and process recovery require separate implementation and
qualification. Synthetic transports do not qualify a paid or subscription account.
Node 24 or later remains required.

Refs: #512, #514, #515.
