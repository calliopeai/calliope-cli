# Counted request admission

Default execution reserves the full live-discovered input capacity plus the
configured output limit. Native Anthropic calls may opt into a smaller reservation
using the free Messages token-count endpoint and operator-reviewed billing evidence.
This is an **estimate policy**, not a guarantee from the provider: reserve twice
the returned input count plus 1,024 tokens, capped at the discovered input capacity.
Output always reserves the configured maximum, including thinking tokens. Any
reported usage overrun freezes subsequent execution; an in-flight provider charge
cannot be undone. Failed, interrupted and missing-usage calls retain reservations.

## Reviewed local evidence

Create a private `~/.calliope-cli/billing.json`, or select a private file with
`CALLIOPE_BILLING_FILE`. It must be outside the worker project, without directory
aliases, symlinks, hardlinks or group/world write access. The maximum is 128 KiB
and 64 unique profiles. No models or prices are bundled in the CLI.

```json
{
  "version": 1,
  "profiles": [{
    "provider": "anthropic",
    "model": "<exact live-discovered model ID>",
    "target": "<providerTarget('anthropic').key>",
    "checkedAt": 0,
    "expiresAt": 0,
    "sources": ["https://platform.claude.com/docs/en/about-claude/pricing"],
    "prices": {"input": 0, "output": 0},
    "capabilities": {"tools": true, "streaming": true},
    "admission": "provider-count-v1"
  }]
}
```

The placeholders are deliberately invalid until reviewed. Set millisecond epoch
timestamps with an expiry no more than seven days after review. Obtain the target
digest from the configured endpoint's health identity. Prices are USD per million
tokens and must upper-bound every applicable charge on this adapter path, including
cache writes and reads; use the larger of these rates and live-discovered rates.
This adapter sends client tools, with no cache control, fast mode or server tools.
Do not reuse a provider price for a gateway without checking its billing terms.
No keys, private prompts or responses belong in this file. Source URLs cannot carry
credentials, query strings or fragments. This file is operator authority, never
generated by a worker or imported from an agent artifact.

Capability evidence fills only fields omitted by discovery. A live negative always
rejects the request. Models still require fresh live discovery and valid input/output
limits. This release implements counting only for the Anthropic Messages protocol;
other providers retain capacity admission. An unmatched profile is ignored; a
matching expired or malformed profile fails closed with remediation in the error.
Deleting or changing a profile revokes a pending counted admission before dispatch.

## Dispatch and recovery

The adapter builds one serialization shared by counting and generation. A SHA-256
digest binds system instructions, tool schemas, tool-result replay, model, thinking,
output limit and streaming mode. Each shared retry counts again. Counting has a
15-second timeout, zero SDK retries and the parent's cancellation signal. It creates
no inference reservation. Before paid dispatch, Calliope rechecks the endpoint,
profile, original execution authority and count freshness, then reserves both project
and inherited run/agent allowances. A changed serialization cannot be dispatched.

Execution reservation records retain optional `quoteEvidence` version 1: the reviewed
profile and digest, count method/time/request digest, count, multiplier and slack.
These additive fields remain inside the reservation event's integrity hash. No
prompt bytes are retained in quote evidence. Restart reconstructs charges and proof
from the ledger, including unknown charges. Ordinary project-capped turns put the
same proof into their existing hash-linked policy audit event. Existing headless
orchestration envelopes are unchanged.

## Sources and limitations

Anthropic documents that [counting is free and estimated](https://platform.claude.com/docs/en/build-with-claude/token-counting),
and that counts are model-specific. Review [pricing](https://platform.claude.com/docs/en/about-claude/pricing),
[client tool behavior](https://platform.claude.com/docs/en/agents-and-tools/tool-use/how-tool-use-works)
and [streaming](https://platform.claude.com/docs/en/build-with-claude/streaming)
when creating evidence. The fixed headroom is Calliope's conservative policy choice;
Anthropic does not promise that exact error bound. Operators requiring full-capacity
reservations should leave counted admission disabled. Provider pricing verification
is manual in this slice; URL presence alone does not verify a price.
